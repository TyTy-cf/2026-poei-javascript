
# Exos de révisions


## 1. Table HTML


- Ajouter une barre de recherche dans l'HTML, en haut à droite de la table HTML
  - Faire en sorte de masquer ou afficher, les `<tr>` contenant les caratères rechercher
  - Pas besoin que l'action se réalise sur un bouton "Rechercher", le simple fait de taper dans la barre de recherche suffit


## 2. Module table HTML

- Créer une classe CSS "data-table"
- En Javascript, si cette classe CSS est mise sur une `<table>` HTML, alors on créé en JS la barre de recherche, on la place en haut à droite
- Elle fait le même traitement que dans l'exo 1


## 3. Un peu plus ?


- Sur la même ligne que la barre de reherche, sur la gauche, ajouter le nombre total de `<tr>`affiché
- On veut voir le nombre par défaut, et aussi le nombre actualisé en fonction des données recherchées
